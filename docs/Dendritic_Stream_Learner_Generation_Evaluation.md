# Dendritic Stream Learner: Free-Running Generation Evaluation

## Purpose

Held-out bits per byte measures ground-truth-conditioned one-step predictive
calibration: the cortex predicts, then advances on the real held-out byte. No
learning occurs and ALM is not trained through supervised teacher forcing, but
the true history prevents prediction errors from compounding during scoring.
It therefore does not show whether a learner remains coherent after consuming
its own sampled outputs. Both are required. Low bpb with gibberish generation
means useful compression has been learned without a stable generative manifold.

## Harness

`dendritic_basin_generate` loads the trainer's frozen checkpoint, clears only
episode state, primes the cortex with raw prompt bytes, samples the full
256-way next-byte basin, and feeds each sampled byte back through the same
recurrent path. Learning remains disabled.

It supports:

- greedy decoding with temperature zero;
- temperature sampling;
- top-k restriction;
- nucleus/top-p restriction;
- deterministic sample seeds;
- optional stopping at a learned story boundary; and
- arbitrary prompt bytes from text or a file.

Goal-conditioned checkpoints additionally accept `--goal-apical-weight`. This
overrides the frozen checkpoint in memory without changing its anatomy, making
matched gain-on/gain-zero causal ablations possible. Each generated sample
records how many approved goal-route switches occurred; a textual difference
with zero switches cannot be credited to the goal mechanism.

The telemetry also separates active goal-context calls, alternative-route
proposals, learned denials, and executed switches. This localizes a silent
ablation: no context means the attractor failed to persist; no proposal means
route restoration did not differentiate candidates; denials implicate the
metaplastic permission; switches without output divergence mean the selected
route did not materially change the sampled basin.

Each seed retains exact generated bytes and per-sample diagnostics. The report
also aggregates boundary-completion rate, UTF-8 validity, printable fraction,
length, distinct four-grams, and zlib compressibility across the sweep so that
one unusually good continuation cannot conceal unstable free-running behavior.

Every report preserves generated bytes as hexadecimal as well as readable text.
This prevents malformed encoding or control bytes from being silently hidden.

## Diagnostics

Each sample reports:

- strict UTF-8 validity and replacement-character count;
- printable ASCII fraction;
- empirical byte entropy;
- generic zlib compression ratio for longer phrase-level loops;
- longest identical-byte run;
- distinct 2-, 3-, and 4-gram fractions; and
- whether a story boundary was generated.

These catch encoding collapse, loops, and premature termination, but they do
not measure story meaning. Entity persistence, event order, contradiction,
prompt adherence, and recovery after an injected bad byte require separate
controlled continuation probes.

## Full TinyStories Checkpoint Plan

Once `runs/alm_phase40_full_tinystories/checkpoint.pkl` exists, evaluate at
least:

1. greedy generation to expose the dominant attractor;
2. temperature 0.6 with top-k 16;
3. temperature 0.8 with top-k 32; and
4. several prompts and seeds, including prompts not copied from training.

Example:

```powershell
python -m manifoldflow.experiments.dendritic_basin_generate `
  --checkpoint runs/alm_phase40_full_tinystories/checkpoint.pkl `
  --prompt "Once upon a time" --max-new-bytes 500 `
  --temperature 0.8 --top-k 32 --samples 5 `
  --output runs/alm_phase40_full_tinystories/generation_t08_k32.json
```

Generation is a functional outcome, not a replacement for bpb. The report
should present both without using one to excuse failure on the other.

For a goal-conditioned checkpoint, repeat the same prompt, seed, temperature,
top-k, and top-p with the learned gain and with `--goal-apical-weight 0`. Compare
boundary completion, loop diagnostics, exact bytes, and the recorded switch
count. This paired intervention is the primary long-range-coherence test.

`dendritic_basin_goal_generation_ablation` performs this intervention in one
run. It loads independent goal-on and goal-off copies, evaluates several
prompts with matched random streams, and reports the first divergent byte for
every pair. Its invariant `changed_without_switch_count == 0` guards against
mistaking random-stream or state leakage for a goal effect. The standard suite
includes an open story beginning, entity continuation, fear-resolution, and a
multi-step rescue prompt.

## 300MB-Exposure Pilot

The existing 151.38MB-body Phase 39 checkpoint successfully free-runs from
`Once upon a time`. Greedy decoding immediately produces recognizable syntax:
`there was a little girl named Lily`, then collapses into a repeated
park/crayon/friends phrase attractor. Over 2,000 generated bytes it remained
valid UTF-8 and printable ASCII, but did not emit a story boundary, had only
0.109 distinct 4-grams, and compressed with zlib to 9.7% of its original size.

Temperature 0.8/top-k 32 avoids the exact phrase loop over 300-byte samples and
produces grammatical story-like fragments. Semantic continuity still fails:
pronouns change referents, objects change roles, and adjacent sentences do not
form a durable event chain. The pilot therefore demonstrates a working raw-byte
generator and strong local language structure, not usable story generation.
The full-exposure checkpoint was subsequently compared under identical prompts
and decoding settings; see
[`Dendritic_Stream_Learner_Phase46_Full_TinyStories_Baseline.md`](Dendritic_Stream_Learner_Phase46_Full_TinyStories_Baseline.md).

The smallest directly relevant public transformer baseline is
[`raincandy-u/TinyStories-656K`](https://huggingface.co/raincandy-u/TinyStories-656K):
two Llama layers, hidden size 128, a learned 2,048-item BPE vocabulary, BF16
weights, and two training epochs. Its model-card sample is grammatical but also
repetitive and event-inconsistent. That places the Phase 39 sample in a
plausibly comparable qualitative tier, not a controlled victory. A fair result
requires identical prompts and sampling plus likelihood converted to bits per
raw source byte. The 151MB ALM is also much larger in serialized memory than
656K BF16 parameters; its present interest is learning mechanism and exposure
efficiency, not footprint superiority.

## Full-Exposure Outcome

The full 1.924GB-exposure checkpoint scored 1.135893 validation bpb with a
491.51MB body. Under a matched ten-seed temperature 0.8, top-k 32, top-p 0.9
sweep, 60% of samples emitted a story boundary versus 80% for the 300MB
checkpoint. Mean generated length rose from 442.5 to 722.5 bytes while mean
distinct four-grams fell from 0.8037 to 0.6959 and mean zlib ratio fell from
0.7121 to 0.5652. Its greedy continuation repeated an exact phrase cycle for
2,000 bytes without terminating.

The added exposure therefore improved ground-truth-conditioned bpb by 0.01923
while growing anatomy 3.25 times, but did not improve the measured free-running
failure. This checkpoint remains the clean pre-long-range integration control.
