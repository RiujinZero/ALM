# Shared-goal convergence and free-generation evaluation contract

## Status

Prospective design. No result may be called a mechanism pass from this document
until the implementation, input hashes, exact checkpoint schedule, and output
schema are frozen. Protected test payloads remain sealed.

## Why this contract exists

A newly attached route through the existing 500 MB checkpoint is an interface
probe, not a convergence experiment. The checkpoint learned its retained
features and byte transitions without the proposed consequence or completion
path. A small or null immediate effect can therefore mean any of:

- the base lacks valid output support;
- the receiver cannot express the signal;
- the new state is uninformative;
- the state-to-prefix interaction has not been trained enough; or
- the mechanism is genuinely ineffective.

The frozen test can separate some of these cases, but it cannot by itself reject
the underlying mechanism. REPORT2 specifically requires state-by-production-
prefix interactions to learn while observing continuation bytes. REPORT4's
successful learned potential received 2.4 million balanced prefix rollouts per
seed. A few thousand logged responses followed by one frozen routing pass is
not a comparable training opportunity.

## Scientific questions

The study separates three questions that must not be collapsed into one score:

1. **Signal observability:** does an external later event contain predictive
   information beyond the causal state alone?
2. **Receiver/trainability ceiling:** with a correct evaluation-only state or
   action, can a trained state-by-prefix path make generated bytes follow it?
3. **End-to-end causal mechanism:** can a causally available learned state
   acquire the same control and improve independently checked free generation?

Teacher-forced BPB can diagnose support, calibration, and collapse. It does not
select a mechanism and cannot veto a robust behavioral improvement.

## Modality-independent core

The reusable mechanism accepts only:

```text
causal persistent event state
    + supported coarse action or completion-potential activity
    + evolving emitted-symbol prefix
    -> next-symbol modulation
    -> later external outcome
    -> delayed local credit
```

It does not know about chat roles, words, facts, or human-authored goal labels.
The chat adapter supplies USER/ASSISTANT event boundaries, byte symbols, and the
strictly later USER outcome. An audio adapter could supply acoustic events and
quantized acoustic symbols; a vision/control adapter could supply frames or
actions and later sensory outcomes without changing the learning contract.

## Staged execution

### Stage 0: train-only signal observability

The NCCA proxy assay may run before native actuation because it loads training
conversations only and makes no generation claim. A positive result means only
that anonymous logged response actions predict some strictly later USER bytes
beyond the chosen causal state and matched shuffled control. It does not mean
the action was desirable or caused the later event. A negative result at one
training depth does not reject completion-potential learning.

### Stage 1: frozen receiver ceiling

Use the same 500 MB checkpoint, prompts, sampling draws, and reset discipline
for every arm. Supply an evaluation-only correct action or exact child
completion potential. Compare it with native bypass, a causal learned state,
wrong-history, swapped-state, and disconnected controls.

This stage asks whether the proposed byte interface exposes existing base
support. Failure rejects that receiver configuration. It does not reject a
path that would need to co-adapt during training.

### Stage 2: bounded convergence pilot

Initialize every conditional path identically. Keep the 500 MB base fixed as a
common support prior for this tractable pilot, but train the persistent-state,
action/potential, and emitted-prefix interaction on observed response bytes.
Replay complete conversations without crossing episode boundaries.

Use geometric checkpoints at cumulative pass fractions or equivalents:

```text
0, 0.25, 0.5, 1, 2, 4, 8 passes
```

The unit of exposure is both unique conversations and byte-prefix updates.
With 6,567 response transitions capped at 128 bytes, one full pass supplies at
most 840,576 local prefix updates; four passes can therefore reach roughly 3.36
million updates, comparable in order of magnitude—not information content—to
REPORT4's per-seed calibration budget. Report unique trajectories separately so
repeated exposure is never described as new data.

Run arms sequentially and train them on identical ordered bytes, update
opportunities, seeds, table allocation, and time ceilings. Required arms are:

- native exact bypass;
- evaluation-only oracle action/potential receiver ceiling;
- causal learned action/potential with trained coupled path;
- causal state with state-by-prefix conjunctions frozen;
- allocation- and active-feature-matched additive-wide path;
- stratified outcome/action shuffle with the same updates;
- selected action disconnected from the writer; and
- pending-only or reset persistent state.

The oracle and causal arms should share conditional writer weights when the
question is action selection. Otherwise an independently better-trained oracle
writer would confound representation with lexicalization.

### Stage 3: native co-adaptation

Run only after Stage 2 shows a controlled held-out behavioral slope. Integrate
the same sparse interaction into the native learning path and continue the base
and mechanism from identical checkpoint copies. The native-continuation control
receives the same new corpus bytes and consolidation schedule with the new path
disconnected. A capacity-matched control receives the same auxiliary storage
and updates with stratified shuffled outcomes.

The Stage 3 curve, not Stage 1, decides whether the mechanism can reorganize a
500 MB model. Optimize memory only after a mechanism passes; the final retained
configuration must then return to the 500 MB total-body constraint.

## Data separation and anti-memorization

- Keep complete conversations in one fold and cluster all uncertainty by
  conversation.
- Fit the action tokenizer, outcome evaluator, selector, and writer on their
  declared folds only for the generation study. A tokenizer that sees audit
  response bytes is permissible for a train-only information census but not for
  the final held-out generation claim.
- Remove exact and near-duplicate prompt/response pairs across folds before
  freezing inputs. Report the exclusion rule and counts.
- For each output, report longest copied training substring, nearest training
  response similarity, and verbatim-copy rate.
- Include novel entity/value bindings, altered output order, distractor turns,
  long interruptions, and unseen local response prefixes.
- Generated commitments never overwrite the external evidence used by the
  checker or reward evaluator.
- Development may control stopping and choose only a predeclared small grid.
  Audit and protected test folds never control training duration.

## Primary free-generation endpoints

Freeze every checkpoint before evaluation. Generate 128 bytes with paired
random draws and no teacher forcing after the prompt. The same prompt/seed row
is the resampling unit across arms.

The primary endpoint is independently checked task completion and coherence on
a held-out free-generation suite. The suite must require a response to preserve
and use earlier bindings, satisfy an explicit outstanding obligation, maintain
its own commitments, and terminate appropriately. The checker consumes the
original evidence and emitted bytes; it cannot read the mechanism's score.

Required behavioral diagnostics are:

- correct-goal versus swapped-goal sensitivity;
- correct-history versus wrong- or swapped-history sensitivity;
- obligation completion, contradiction, and unsupported-claim rates;
- within-response commitment consistency;
- topic/reference discrimination against a crossed response;
- action compliance when anonymous actions are under test;
- unique-output count, repetition/looping, printability, termination, and
  verbatim-copy rate; and
- route use and first-divergence position.

Natural-chat samples remain part of the audit panel, but diversity,
printability, byte-ngram similarity, and the mechanism's own later-user score
must not be relabeled as thoughtful coherence. A pass needs the independent
obligation checker, plus blinded qualitative inspection before promotion.

Teacher-forced BPB is reported beside these results as a non-collapse and base-
support diagnostic. It is secondary even when statistically precise.

## Learning-curve decision rule

Do not require a dramatic checkpoint-zero difference. Promote a Stage 2 arm
only when all of the following hold on development and repeat with the same sign
on the untouched audit fold:

1. the free-generation task-completion advantage over native continuation and
   the strongest capacity-matched control is positive with a conversation-
   clustered 95% interval above zero;
2. correct state/goal beats its swap, shuffle, disconnect, and reset controls;
3. the advantage increases across at least two predeclared training intervals
   and is not explained solely by copying or degeneration; and
4. the oracle receiver ceiling is above the causal arm, or the causal arm has
   already saturated that ceiling.

Stop training only for a numerical/invariant failure, the preregistered maximum
bytes/updates/wall time, or a development-only plateau across three consecutive
geometric checkpoints. A plateau requires both the primary task endpoint and
route utilization to remain within their predeclared equivalence bands. Never
stop because audit/test looks weak, and never call a single early null a
mechanism falsification.

## Tractability and storage

For the first pilot, use one active arm at a time. A 14-bit by 256-symbol float32
writer occupies 16 MiB; three matched writers occupy 48 MiB. Together with the
500 MB native checkpoint and interpreter overhead, expected peak memory is
roughly 0.7–1.0 GB. A short structural diagnostic should take about 10–20
minutes, and the predeclared four- to eight-pass confirmation should be capped
at one to two hours.

Persist the new pathway's sparse/delta state and the exact input/config hashes
at geometric checkpoints. Do not duplicate a full 500 MB checkpoint at every
point; retain the immutable base once and reconstruct each auxiliary snapshot
against it.

## Interpretation boundary

A positive curve supports a trained, prefix-sensitive consequence/completion
pathway. It does not establish human utility, causal effects on an interlocutor,
or autonomous discovery of a universally correct goal. A flat causal curve
with a rising oracle curve localizes the failure upstream in state/action
learning. A flat oracle curve localizes it in support or the productive
interface. Only a flat, well-trained, controlled curve at the declared budget
can count against the mechanism itself.
