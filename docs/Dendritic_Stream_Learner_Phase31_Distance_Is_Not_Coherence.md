# Phase 31: Distance Is Not Coherence

## Rejected mechanism

A controlled long-range organ added sparse axons at fixed delays of 4, 8, 16,
32, 64, and 128 bytes. Surprise recruited a delayed assembly together with
the current local assembly; living fibers competed by measured predictive
utility. The mechanism causally solves synthetic sequences whose immediate
contexts are identical and whose distinguishing evidence occurs at a fixed
distance.

It does not improve TinyStories.

All delayed fibers lost their utility competition to the local predictor.
Distance therefore allocated anatomy and reduced throughput without creating
coherence. The control remains named `DelayedOpponentAttractorControl` so the
failed hypothesis stays executable but is not mistaken for the production
direction.

## Biological correction

The useful analogue is an episodic index, not a longer character history.
Local columns should first form stable content assemblies. At event boundaries,
a small indexing organ binds the simultaneously active distributed pattern.
Later partial cues reactivate the index, which reinstates relevant cortical
assemblies. A current byte prediction can then receive sparse top-down residual
evidence from reinstated content.

For raw TinyStories bytes, the next developmental ladder is:

1. boundary-sensitive sequence assemblies grown from recurring receptor paths;
2. persistent content assemblies that survive changes in local byte activity;
3. sparse episodic indices born from coactive content assemblies near event
   boundaries;
4. cue-driven pattern completion and top-down residual prediction;
5. utility-gated consolidation or forgetting of indices.

This preserves the nature-shaped constraint: higher coherence must emerge from
stable events and reinstatement, not from a predefined token window or dense
attention matrix.
